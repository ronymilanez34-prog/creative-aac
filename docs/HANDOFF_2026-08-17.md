## 1 · מצב הפרויקט

**קיים ועובד:**
- אפליקציית Flutter: אשף בניית סיפור (3 שלבים, לוקאלי) + מסך "בן-לוויה"
  לשיחה חופשית נתמכת, כולל הקראה בעברית.
- System prompt v0.1 (`docs/prompts/companion_system_prompt.md`) — חוזה JSON,
  מנגנון "אישור לא הכרעה", חריצי `{{PROFILE}}`.
- שלד Cloud Function (`functions/`) — מפתח API בצד השרת, מוגדר על Haiku 4.5.
- מסמכי חזון מעוגני-מחקר: `VISION.md`, `docs/AAC_LEVELS.md`.

**חשוב לדעת:** האפליקציה רצה כרגע על **Mock בלבד** (תסריט קבוע של 5 צעדים).
ה-Cloud Function קיימת אך **לא פרוסה ולא מחוברת**. אין עדיין AI אמיתי בלולאה.

**הפער הגדול ביותר:** אין פרופיל של אריק — אף שורה. זה הצעד הבא.

## 2 · החלטות שהתקבלו בסשן

### סדר עדיפויות עד היעד של אריק
1. **פרופיל של אריק** — התנאי לכל השאר (סכמה מוכנה, ראה סעיף 4).
2. חיבור AI אמיתי: פריסת ה-Function + כתיבת `ClaudeCompanionService` בצד Flutter
   (הממשק `CompanionService` כבר מוכן — אף מסך לא משתנה).
3. לולאת אישור/תיקון שנשמרת (לוג ניחוש→תיקון).
4. מצב מלווה/קלינאי לעריכת הפרופיל.
5. בדיקה אמיתית עם אריק — אפשר כבר עכשיו עם ה-Mock (חינם, בלי רשת).

### מנופי דיוק (לפי תמורה מול מאמץ)
- פרופיל עשיר בפרומפט — המכפיל הגדול ביותר, מעל כל שיפור טכני.
- Structured Output במקום פרסינג טקסט של JSON.
- דוגמאות few-shot של קלט דליל בסגנון אריק.
- שליחת היסטוריית שיחה מלאה (היום נשלח רק התור האחרון).
- לוג ניחוש→תיקון — גם משפר פרופיל, גם הקורפוס העתידי.
- מודל: Haiku עכשיו; שדרוג ל-Sonnet = שינוי שורה אחת אם הפירוש לא מספיק.
- טמפרטורה: להפריד בעתיד — פירוש קר ומדויק, יצירה חמה (היום 0.7 לשניהם).

### פרטיות ודאטה
- ✅ **יש אישור כתוב מההורים.**
- **כלל הברזל: הדאטה הגולמי נשאר מקומי. לפרויקט נכנס רק הזיקוק.**
  שם פרטי בלבד, בלי פרטים מזהים.
- דאטה שנשלח ל-Anthropic דרך ה-API לא משמש לאימון מודלים; המודל לא "זוכר"
  בין שיחות — כל הזיכרון אצלנו, בפרופיל.
- ייצוא מהאייפד: או ייצוא מתוך אפליקציית התת״ח (מייל/וואטסאפ — הכי פשוט),
  או חיבור בכבל למק (Trust + קוד המכשיר; רק לשונית Files; **לא** Sync/Restore/
  Erase; לא צריך Apple ID של הבעלים). ❓ עדיין לא ידוע באיזו אפליקציית תת״ח
  אריק משתמש — לברר.

### עלויות
- Haiku: ~$0.003 לתור (~אגורה); שימוש יומי מלא ≈ $2–3 לחודש.
- Firebase: שכבת חינם מכסה הכל בהיקף אישי (נדרש כרטיס בתוכנית Blaze).
- Anthropic API: prepaid, מינימום ~$5; להגדיר תקרת הוצאה.
- בהמשך: prompt caching מוזיל את החלק הקבוע ב~90%.

### מסחור (לעתיד — לא עכשיו)
- מנוי בונים רק אחרי ולידציה עם אריק + עוד משפחות.
- כשמגיעים: RevenueCat (חנויות, עמלה 15–30%) ± Stripe באתר; בדיקת "מנוי פעיל"
  ב-Cloud Function — הארכיטקטורה הקיימת (שרת מתווך + Auth) כבר ערוכה לזה.
- מחיר שוק סביר: $8–15/חודש; שוליים בריאים מול עלות של $2–5 למשתמש.
- לזכור את המסלול המוסדי (גני תקשורת, קליניקות) — הלקוח המשלם בתת״ח הוא
  לרוב לא המשתמש.

### אימון מודל אמיתי (fine-tuning)
- לא עכשיו: Anthropic לא מציעה fine-tuning פתוח (חריג: Haiku דרך Bedrock);
  מודל פתוח + LoRA אפשרי אבל דורש 1,000–10,000 דוגמאות — שלא קיימות.
- **האפליקציה היא מכונת יצירת הדאטה**: לוג האינטראקציות (בהסכמה) הוא הקורפוס
  העברי שלא קיים בעולם. לעצב כל רשומת לוג כך שתהיה דוגמת-אימון עתידית
  (קלט, ניחוש, תיקון, אישור).
- הסולם: פרומפט+פרופיל ← RAG ← קורפוס נצבר ← fine-tuning בהיקף.
- גם מודל מאומן לא יכיר את אריק — ההיכרות תמיד מהפרופיל. אימון משפר את
  שכבת הבסיס, לא מחליף את הלב.

### יצירה מעבר לסיפורים (עוגן ב-VISION §9)
- שלושה עקרונות: המורכבות אצל המכונה; **בחירה בין תוצאות מרונדרות** במקום
  תיאור במילים; אפשרויות **נוצרות** ולא קבועות (4 צ'יפים = חלון, לא אוצר מילים).
- פתיחת המרחב: ייצור דינמי, "עוד", עומק-דרך-צירוף (4×10 צעדים = מיליון+
  מסלולים), מצלמה/ציור/צליל כאוצר מילים, יצירות עבר נכנסות לפרופיל.
- החזון: **שיעור תכנות בתת״ח** — קבוצה שכל אחד בה בונה עולם, והיצירות של
  הילדים הן אוצר המילים זה של זה.
- טכנית: אותה לולאה בדיוק — `creation_update` מחליף צורה (פסקה ← HTML ב-WebView).

### עקרון המניפסט (עוגן ב-VISION §0)
> **"אני נותן להם את המכחול — הם הציירים."**
> המכחול מתאים ליד — לא היד למכחול. כל פיצ'ר נמדד מול זה.

### מבחנים ← הנחיות ל-AI (עוגן ב-docs/ASSESSMENT_TO_PROMPT.md)
- הצינור: אפיון (קלינאית+הורים) ← פרופיל JSON מובנה ← שני צרכנים:
  הפרומפט + תצורת הממשק.
- כל ציר Feature Matching = שדה עם טבלת תרגום קבועה (רמת Comm Matrix קובעת
  את שפת ה-AI; ערוץ גישה את הממשק; האידיולקט מזין את מנוע הפירוש).
- **פרומפט לתוכן, קוד לבטיחות** — מגבלות קריטיות נאכפות גם בקוד.
- האפיון = נקודת התחלה, לא כלוב; שינויי אפיון רק באישור אנושי.
- מימוש: v1 מילוי JSON ידני (מספיק לאריק) ← v2 טופס באפליקציה ← v3 הצעות
  מנתוני שימוש באישור קלינאי.

## 5 · עקרונות-על שנקבעו (תזכורת מרוכזת)

1. **המכחול** — הכלי לא מכתיב; מי שמחזיק קובע.
2. **כלום עליי בלעדיי** — שום שינוי אוטומטי בפרופיל/אפיון בלי אישור אנושי.
3. **הדאטה הגולמי מקומי; לפרויקט רק זיקוק** — שם פרטי בלבד.
4. **פרומפט לתוכן, קוד לבטיחות.**
5. **הקול האותנטי קודם** — התרגום משרת, לא מיישר.
6. **כל אינטראקציה היא דוגמת-אימון עתידית** — לתכנן את הלוג מהיום הראשון.
