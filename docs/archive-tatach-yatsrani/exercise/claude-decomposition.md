# תרגיל פירוק סיפור — הפירוק שלי (Claude)

**לא להראות למשתתפים לפני שסיימו.**

נכתב לפני שראיתי פירוק אנושי כלשהו, כדי שההשוואה תהיה הוגנת.

## הפירוק

העיקרון שהפעלתי: לשמר עושה + פעולה + מושא, רגש רק כשהוא הנקודה של
המשפט, וויתור על תיאורים שאינם מקדמים את העלילה.

## ניבויים — איפה אני מצפה שהפירוק האנושי יתבדל

רשומים מראש; נבדוק מול המציאות:

1. **משפט 9** — אני מיזגתי שלוש פעולות ל"בלגן". אדם כנראה יפרט
   (`אכל` `ישב` `שבר`) או יבחר פעולה אחת. כאן הפער הצפוי הגדול ביותר.
2. **מילות רגש** — אני שמרתי `פחד` ו`שלי`; יש סיכוי שאדם יוותר עליהן
   לטובת עוד פעולה. אם כן — זה ממצא חשוב על מה בני אדם חושבים שרצועה צריכה.
3. **משפט 4** — ויתרתי על "להתקרר". אם האדם ישמר אותו, סימן שהוא מחזיק
   סיבתיות ואני מחזיק רק רצף.
4. **גוף הרצועה** — אני צפיתי שאדם ישתמש בפחות "מילים דקדוקיות"
   (`של`, `מדי`) ויותר במילות תוכן.

## איך משווים (אחרי שיש פירוק אנושי)

לכל משפט, לסמן אילו אלמנטים כל פירוק שימר:
**מי / עשה מה / למה או על מה / איך הרגיש**. לא להשוות מילים מדויקות —
נרדפות זהות לענייננו (`הלכו`=`יצאו`, `תינוק`=`קטן`).

- הסכמה על אלמנט → גרעין יציב, נכנס לכללי הפירוק של המוצר
- התבדלות → לתעד מי צדק מול חלק ב' (הסיפֵּר בקול): אם המספר/ת הצליח/ה
  לשחזר את המשפט מהרצועה — הפירוק ההוא ניצח

## מה חוזר מהתרגיל אל המוצר

1. זוגות משפט↔רצועה מוסכמים → few-shot בפרומפט ההרחבה של probe2
2. המילים החוזרות → מועמדות ללוח ליבה נרטיבי
3. גודל רצועה אופייני (3–5) → כיול ציפיות UI
4. הפערים שלי מול אדם → תיקוני כיול לפונקציית הפירוק
