# ארכיון: מה שהועבר מהרפו tatach-yatsrani (20.10.2026)

עד אוקטובר 2026 התקיימו שני פרויקטים במקביל: הרפו הזה (אפליקציית פלאטר, הפיילוט) והרפו
`tatach-yatsrani` (אתר סטטי ב-Firebase Hosting עם ניסוי ווב `/chat/`, ניסויי probe, ותרגיל
המדריכים). ב-20.10 הוחלט (רוני): **הבית הוא creative-aac בלבד.** האתר הישן הוחלף בדף הפניה
לאפליקציה, והמסמכים שלו עברו לכאן.

## מה יש כאן
- `arik/` — פרופיל הסיד של אריק (`profile-seed.json`), סיד הלקסיקון, שאלות לצוות. **זה הנכס
  החשוב ביותר בתיקייה.**
- `exercise/` — ניסוי המדריכים (11.8.2026): הממצאים (`findings.md`, "קיר הדקדוק"), המדריך, לוח הסמלים.
- `plan.md`, `aac-assessment-research.md`, `rosetta-principles.md`, `architecture-chat.md`,
  `merge-creative-aac.md` — התוכנית, מחקר ההערכה, העקרונות, ארכיטקטורת ניסוי הווב, ומסמך המיזוג
  המקורי (17.8).
- `creative-aac-old-copies/` — עותקים ישנים (אוגוסט) של VISION ושל פרומפט המלווה, כפי שהיו ברפו
  השני. המקור החי: `../../VISION.md`, `../prompts/companion_system_prompt.md`.

## מה לא הועבר
קוד הניסוי הווב (`public/chat`, `public/probe*`, `public/exercise`) נשאר בהיסטוריית git של
`tatach-yatsrani` (קומיט `12d67bf` ומטה). הרעיון היחיד משם שעוד רלוונטי: **לוח אישי קבוע** —
המילים של האדם, במיקומים שלא זזים (LAMP), עם תמונות אמיתיות במכשיר בלבד. ראה `architecture-chat.md`.
